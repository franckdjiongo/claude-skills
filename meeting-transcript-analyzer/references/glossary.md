# Glossaire de normalisation - Projet Temps Chantier

Applique systématiquement ces corrections aux termes mal transcrits dans les transcriptions.

## Systèmes et technologies

| Terme correct | Variantes à corriger |
|---------------|---------------------|
| Dayforce | Day Force, Day four, DayFour, DF, DayForce |
| AS400 | AS 400, AS-400, AS/400, A S 400, ace four hundred, iSeries |
| MIR | M I R, MIRR, mire |
| Dataverse | Data verse, Data-verse, DV |
