# Path-scoped rules to install

In addition to the 8 core rules:

  • ui-components.md (paths: src/**/components/**, pages/**):
    • LocalizedString + useContent() mandatory for user-facing strings
    • Tailwind tokens only (no inline hex/rgba)
    • dark: variants for dark mode (when applicable)
    • Brand palette enforced
    • Accessibility: aria-label, alt text, semantic HTML, keyboard navigation
    • Touch targets 44px minimum (36px for dense controls)
    • No <a href> for in-app navigation (use <Link> / <NavLink>)

# Source-of-truth doc structure

Three canonical docs:

  1. docs/<project>-spec.md — FUNC-XX, RA-XX, VAL-XX
  2. docs/data-model.md — schema, contracts (frontend types + backend if applicable)
  3. docs/composants/catalogue-composants.md — C-XX components

Add HTML prototypes:

  • docs/composants/prototypes/<C-XX>-<name>.html (one per C-XX, hand-coded reference)

# Tooling stack

  • ESLint 9 flat config (eslint.config.js)
  • Prettier 3+ with .prettierrc
  • Vitest 4 for component/hook/integration tests
  • node:test for config/build assertions (split runner)
  • Tailwind 3-4 with design tokens in tailwind.config.js
  • Husky 9 + lint-staged 16 for pre-commit
  • TypeScript strict mode

# Tests

// tests/<Component>.test.tsx
import { render, screen } from '@testing-library/react';
import { ContentProvider } from '@/contexts/AppContext';

it('renders the main heading in French', () => {
  render(
    <ContentProvider initialLanguage="fr">
      <HomePage />
    </ContentProvider>
  );
  expect(screen.findByRole('heading', { level: 1, name: /accueil/i })).resolves.toBeTruthy();
});

Forbidden:

  • container.querySelector — use Testing Library queries
  • .toMatchSnapshot() — brittle
  • findBy* for elements that should be there immediately (use getBy* + await)

# Common gotchas

  • useEffect + setState heuristic flagged by quality-checks (state sync anti-pattern)
  • Hardcoded colors caught by colors-hex and colors-rgba checks
  • i18n bypass via language === 'en' ternaries caught by i18n-ternary check
  • File size > 300 lines caught by file-size check
  • Money: use integer cents, not floats
  • Errors: throw typed errors with codes; map codes to translations
