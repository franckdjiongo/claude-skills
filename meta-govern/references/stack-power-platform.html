Stack Pack — Power Platform (Code App + Dataverse)

When meta-govern detects: package.json includes @microsoft/power-apps, power-apps, OR power.config.json exists.

# Layout reference

Default architecture pattern: feature-first (no native router in code apps). Layout: src/{features,shared,services,models}. See architecture-patterns.html § Power Apps code app.

# Skills to install (BOOTSTRAP)

In addition to the 5 core skills, install these (already globally available — pin via project skills):

  • add-dataverse — adds Dataverse tables, generates TS models/services
  • code-app-create — scaffolds new code app
  • code-app-connect — connects to data sources
  • code-app-deploy — deploy + ALM + monitoring
  • pp-solution-sync — sync solution exports
  • secure-pa-http-trigger — HTTP-trigger Entra auth migration

For palier 2+:

  • dataverse-audit (project-level skill scaffolded by meta-govern) — 11-check repository audit

# Path-scoped rules to install

In addition to the 8 core rules:

  • dataverse-and-sdk.md (paths: src/**/repositories/**, src/**/mutations/**):

    • FormattedValue ban (CRITICAL)
    • Column registry compliance
    • @odata.bind quirks
    • GUID case sensitivity
    • Formula-column filter incompatibility
    • Date normalization
    • Mock format fidelity for tests

  • data-layer.md (paths: src/**/data-layer/**):

    • 3-layer architecture: Repositories → Mutations → Actions on top of generated SDK
    • One repository per table
    • Mutations must invalidate query keys
    • No raw SDK calls in components

# Source-of-truth doc structure

Three canonical docs:

  1. docs/<project>-spec.md — FUNC-XX, RA-XX, VAL-XX
  2. docs/lexique-donnees-dataverse.md — tables, columns, OData, lookups, option sets
  3. docs/composants/catalogue-composants.md — C-XX components

Add machine-readable column registry:

  • docs/dataverse-columns/manifest.json (synced from lexique by update-manifest script)
  • Enforced by dataverse-audit Check 11

# DDD mapping

If DDD score ≥ 10:

  • Bounded Context = Dataverse environment (often 1:1)
  • Aggregate transactional boundary = C# plugin sandboxed transaction
  • Process Manager = Power Automate flow
  • Mapper-as-ACL = TS Mapper class at the domain/infrastructure boundary

# Common gotchas (encoded in rules + hooks)

  • FormattedValue is forbidden — use raw value + formatColumn() helper
  • GUIDs are case-sensitive when using @odata.bind
  • Formula columns can't be used in OData filters
  • Lookups need @odata.bind for navigation properties
  • _columnname_value is the lookup ID format
  • Plugin sandboxed transaction = aggregate transactional boundary

# Tests

  • Mock Dataverse responses with format fidelity (use Dataverse-Mock library or manual fixtures)
  • Test repository methods, not raw SDK calls
  • Test mutation cache invalidation
  • State machine tests for journal/workflow status transitions
