macOS Hook Conventions

Source: Claude Code Architecture Research.md macOS sections, observed Apple Silicon patterns in Brillance Décor's lib/hook-utils.mjs.

# The Apple Silicon problem

When Claude Code spawns hook subprocesses, the environment is non-interactive and minimal:

  • PATH may exclude /opt/homebrew/bin (where Homebrew installs node, git, bun, rg on Apple Silicon)
  • No nvm initialization (only available in interactive shells)
  • No ~/.zshrc / ~/.profile initialization (or, worse: those files output to stdout and corrupt JSON responses)

Result: hooks fail silently. The user observes "the hook didn't fire" without obvious cause.

# The fix: explicit PATH

Every hook script (.mjs, .sh, .py) must set its own PATH:

# Node hook (.mjs)

#!/usr/bin/env node
const PATH_PREFIX = "/opt/homebrew/bin:/usr/local/bin:/opt/homebrew/sbin:/usr/sbin:/usr/bin:/sbin:/bin";
process.env.PATH = `${PATH_PREFIX}:${process.env.PATH || ""}`;

# Bash hook (.sh)

#!/usr/bin/env bash
export PATH="/opt/homebrew/bin:/usr/local/bin:/opt/homebrew/sbin:/usr/sbin:/usr/bin:/sbin:/bin:$PATH"

# Python hook (.py)

#!/usr/bin/env python3
import os
PATH_PREFIX = "/opt/homebrew/bin:/usr/local/bin:/opt/homebrew/sbin:/usr/sbin:/usr/bin:/sbin:/bin"
os.environ["PATH"] = f"{PATH_PREFIX}:{os.environ.get('PATH', '')}"

# Profile silence requirement

If ~/.zshrc or ~/.profile outputs anything at startup (welcome banners, prompt previews, version checks), it corrupts JSON hook responses.

Audit:

zsh -c 'exit 0' 2>&1 | head
bash -c 'exit 0' 2>&1 | head

If output non-empty → fix profile to be silent at startup.

# NEVER use nvm in hooks

nvm is initialized only in interactive shells. Hook subprocesses are not interactive.

If the user's node is installed via nvm:

  • The hook will fail with "node: command not found"
  • Even with explicit PATH

Migration: install Node via Homebrew (brew install node) so it lands in /opt/homebrew/bin/node.

# Use #!/usr/bin/env <cmd> shebangs

#!/usr/local/bin/node differs between Intel and Apple Silicon. Use #!/usr/bin/env node always — the env-resolver finds whichever is in PATH.

# Use absolute paths or $CLAUDE_PROJECT_DIR

NEVER:

node ./.claude/hooks/my-hook.mjs   # cwd may be unexpected

ALWAYS:

node "$CLAUDE_PROJECT_DIR/.claude/hooks/my-hook.mjs"   # explicit

$CLAUDE_PROJECT_DIR is set by Claude Code to the project root.

# Permission bits

Some hooks need execute bit:

  • .sh files: chmod +x my-hook.sh
  • .mjs / .js / .py: NOT needed if invoked via node my-hook.mjs / python3 my-hook.py

If you commit a .sh without execute bit, the hook fails silently. Test with: ls -la .claude/hooks/*.sh and verify x permissions.

# Test the hook environment

SessionStart env-check hook (BOOTSTRAP installs):

#!/usr/bin/env node
// .claude/hooks/session-start-env-check.mjs

import { execSync } from 'node:child_process';
import fs from 'node:fs';
import path from 'node:path';

const PATH_PREFIX = "/opt/homebrew/bin:/usr/local/bin:/opt/homebrew/sbin:/usr/sbin:/usr/bin:/sbin:/bin";
process.env.PATH = `${PATH_PREFIX}:${process.env.PATH || ""}`;

const projectDir = process.env.CLAUDE_PROJECT_DIR || process.cwd();
const cacheFile = path.join(projectDir, '.claude/tmp/last-env-check.json');

// Cache: skip if checked < 24h ago
try {
  const cache = JSON.parse(fs.readFileSync(cacheFile, 'utf8'));
  if (Date.now() - cache.timestamp < 24 * 60 * 60 * 1000) {
    process.exit(0); // silent allow
  }
} catch (_) { /* no cache, run check */ }

const required = ['node', 'git'];
const optional = ['bun', 'rg', 'fd', 'jq'];
const missing = [];
const present = [];

for (const cmd of [...required, ...optional]) {
  try {
    execSync(`command -v ${cmd}`, { stdio: 'pipe' });
    present.push(cmd);
  } catch {
    missing.push({ cmd, required: required.includes(cmd) });
  }
}

const blockingMissing = missing.filter(m => m.required);

if (blockingMissing.length > 0) {
  process.stdout.write(JSON.stringify({
    additionalContext: `⚠️  Missing required tools: ${blockingMissing.map(m => m.cmd).join(', ')}. Hooks may fail.`,
  }));
} else if (missing.length > 0) {
  process.stdout.write(JSON.stringify({
    additionalContext: `Optional tools missing: ${missing.map(m => m.cmd).join(', ')} (some skills may not work).`,
  }));
}

// Update cache
fs.mkdirSync(path.dirname(cacheFile), { recursive: true });
fs.writeFileSync(cacheFile, JSON.stringify({ timestamp: Date.now(), present, missing }));

process.exit(0);

# Common Apple Silicon failures (debug checklist)

Symptom Likely cause Fix
Hook fires but does nothing Script crashed silently Run script manually: cat /tmp/test.json | node .claude/hooks/my-hook.mjs
"node: command not found" Missing /opt/homebrew/bin in PATH Add PATH_PREFIX to script
JSON parse error in Claude UI Profile output corruption Silent profile / use zsh -i -c 'echo silent' to verify
Hook works on user A, fails on user B nvm dependency Install Node via Homebrew
Hook works locally, fails in CI Different PATH Force PATH in CI env vars

# Cross-platform considerations

If the user ever moves to Linux/WSL2:

  • /opt/homebrew/bin doesn't exist → use /usr/local/bin priority
  • bun may not be installed
  • Add a platform detection at the top of hook-utils.mjs:
const isMacOSAppleSilicon = process.platform === 'darwin' && process.arch === 'arm64';
const PATH_PREFIX = isMacOSAppleSilicon
  ? "/opt/homebrew/bin:/usr/local/bin:/opt/homebrew/sbin:/usr/sbin:/usr/bin:/sbin:/bin"
  : "/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin";

# Tested patterns from production

# Brillance Décor hook-utils.mjs skeleton

import path from 'node:path';
import fs from 'node:fs';

const PATH_PREFIX = "/opt/homebrew/bin:/usr/local/bin:/opt/homebrew/sbin:/usr/sbin:/usr/bin:/sbin:/bin";
process.env.PATH = `${PATH_PREFIX}:${process.env.PATH || ""}`;

export function projectDir() {
  return process.env.CLAUDE_PROJECT_DIR || process.cwd();
}

export async function readJsonStdin() {
  const chunks = [];
  for await (const chunk of process.stdin) chunks.push(chunk);
  if (chunks.length === 0) return {};
  return JSON.parse(Buffer.concat(chunks).toString('utf8'));
}

export function writeJsonStdout(obj) {
  process.stdout.write(JSON.stringify(obj));
}

export function isFeatureFile(filePath) {
  return /\.(tsx?|jsx?|module\.css|css|mjs|cjs)$/.test(filePath) &&
         !filePath.includes('node_modules') &&
         !filePath.includes('/dist/') &&
         !filePath.includes('/build/');
}

export function isValidateBash(command) {
  return /\b(validate|test|build|typecheck|lint|quality:check)\b/.test(command);
}
