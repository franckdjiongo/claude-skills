Audit and Behind Report — Procedure

Structure du rapport d'audit, contrôles de coût Convex, enregistrement d'un audit et règles du rapport « quels projets sont en retard ».

Type · Référence Source · references/audit-procedure.html Projet · meta-govern

# AUDIT report structure

After audit-project.mjs runs, build the report from these six parts. Output: docs/audits/YYYY-MM-DD-meta-govern-audit.html, severity-tiered findings with proposed diffs. Do not auto-apply.

  1. Inventory — skills/agents/hooks/rules count, line totals, oversized files, orphans (no references, no triggers).
  2. Drift — files past file-size-budget, defensive scaffolding patterns in standing context (see references/anti-pattern-catalog.html), markdown-docs drift (.md files under docs/, missing docs-html toolkit/hook/docs-map/index), versions de modèle figées dans la prose gouvernée (.claude/rules, .claude/skills, .claude/agents — jamais CLAUDE.md ni docs/).
  3. Wiring — hooks declared in settings.json but missing on disk; skills referenced but absent; agents referencing non-existent skills.
  4. Source-of-truth alignment — does CLAUDE.md still point at canonical docs? Has the user added docs not in the router?
  5. Palier — current evolution stage per references/evolution-roadmap.html. Triggers met for next palier? Palier 4 is "release-ready": server CI is an option with a documented local compensation (see ciPolicy), not a hard requirement — don't flag its absence as a gap when ciPolicy is local-compensation.
  6. Anti-patterns — DDD anti-patterns (anemic, IRepository<T>, primitives where VOs exist) AND Claude-Code anti-patterns (oversized files, missing path-scoping, defensive scaffolding, @-imports).

# Convex cost checks

Enforced by audit-project.mjs when the project is Convex (convex in dependencies, or convex/schema.ts, or convex/_generated). Contract: stack-convex.html#frugality-contract.

FindingSeverityTrigger
convex-frugalityMEDIUMA crons.cron/interval/hourly/daily/weekly/monthly(...) registration in convex/crons.ts with no cost-justified marker on its line or in the contiguous comment block above it
convex-frugalityHIGHA `*.testspec.[cm]?[jt]sx? file that imports ConvexHttpClient from convex/browser, or holds a real deployment URL (<token>-<token>-<digits>.convex.cloudsite) next to a fetch(, and does not use convex-test`
convex-mutation-castsHIGHas never/any/unknown on the arguments of a useMutation/useAction call

Placeholder hosts such as example.convex.site do not match. Suites on convex-test (in-memory) conform by definition.

# Recording an audit

node scripts/audit-project.mjs <project-path> --stamp writes three fields into <project>/.claude/.meta-govern.json and changes nothing else: lastAudit (today, ISO date), lastAuditVersion (meta-govern version.json), and auditChecks (the check families that ran, merged with earlier values; convex-frugality for a Convex project). The file must already exist. Without it the script exits 2.

Stamp only after the user accepts the audit. BEHIND reads these fields.

# BEHIND report

node scripts/projects-behind.mjs [--root <dir>] [--exclude <name>]... [--json] [<project-path>...]. Read-only. Projects come from the explicit paths, or from every immediate child of the root (default ~/Desktop/my-projets) that has .claude/.meta-govern.json.

ReasonRule
version-behindmetaGovernVersion older than this skill's version.json, or missing
never-auditedlastAudit null or missing
audit-stalelastAudit more than 28 days old (cadence: every 2 to 4 weeks). Projects with parked: true are exempt
convex-cost-checks-missingConvex project where auditChecks lacks convex-frugality and no file under docs/audits/ mentions convex-frugality

The Convex rule is evidence-based, not date-based. It flags a Convex project audited before the checks shipped (v1.7.1, 2026-07-02) and one whose audit never recorded them. It clears when the project is audited and stamped.

Exit codes: 0 no project flagged, 1 at least one flagged, 2 error. --json prints { current, projects: [{ name, path, version, lastAudit, palier, convex, reasons }] }.
