Stack Pack — Convex Backend

When meta-govern detects: package.json includes convex OR convex/ directory exists with _generated/.

# Layout reference

Default architecture pattern: framework-native + feature-first on the frontend (per architecture-patterns.html); the convex/ directory enforces backend layout (one file per table, schema in convex/schema.ts).

# Agents to install

In addition to the 4 core agents:

  • (Palier 2+) convex-component-auditor — audits ONE @convex-dev/* component in ONE design

# Path-scoped rules to install

In addition to the 8 core rules:

  • data-layer.md (paths: convex/**/*.ts, src/**/queries/**, src/**/mutations/**):
    • Convex hooks only (no fetch direct in components)
    • Bilingual columns denormalized (e.g., nameFr, nameEn not name: { fr, en })
    • Money: integer cents, CAD only, Intl.NumberFormat('fr-CA') on client
    • Errors: throw new ConvexError({ code, message }) with code added to translations
    • Repositories one-per-table (NOT generic IRepository<T>)
    • Mutations must invalidate query keys

# Source-of-truth doc structure

Three canonical docs (same as React+Vite stack pack), plus:

  • docs/data-model.md includes Convex schema + R2 layout + contracts

# Convex schema discipline

  • Schema in convex/schema.ts
  • One file per table: convex/<table>.ts with queries/mutations/actions
  • Generated services in convex/_generated/ (DO NOT EDIT)
  • Use v.string(), v.number(), v.id("table"), v.array(...), v.object({...})
  • Index fields used in queries

# Migration discipline

  • Use @convex-dev/migrations for breaking schema changes
  • Pattern: widen → migrate → narrow
  • Test migrations on a snapshot copy

# R2 integration

If using convex-dev-r2:

  • Files served via signed URLs from R2
  • Upload flow: client → mutation → R2 → mutation marks complete
  • Cleanup: scheduled actions purge orphans

# Tests

  • Use Convex test harness (@convex-dev/test) for backend tests
  • Mock Convex hooks for component tests (use @convex-dev/react test utilities)

# Common gotchas

  • Don't query inside loops (N+1 problem) — use indexed queries or denormalize
  • Watch for OCC (Optimistic Concurrency Conflict) on hot rows — handle retries
  • Aggregate counts denormalized via convex-dev-aggregate component
  • Subscriptions are reactive — careful with high-frequency updates
  • Money is integer cents (avoid floats; use Intl.NumberFormat('fr-CA') for display)
